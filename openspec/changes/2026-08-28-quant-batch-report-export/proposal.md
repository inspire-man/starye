## 背景

候选对比抽屉已经可以为选中的股票批量生成独立研究快照，单股票详情也支持 Markdown 下载和复制。批量研究完成后，用户仍需要逐只打开详情再保存报告，成功结果缺少一次性留存入口；部分失败时，用户也需要知道批量文件具体覆盖了哪些股票。

## 目标

- 在批量研究完成后，提供一次性导出所有成功报告的 Markdown 文件。
- 使用现有单报告 Markdown formatter，保持报告字段白名单、证据来源和缺口语义一致。
- 在部分成功场景中明确导出数量和失败股票代码，方便后续单项重试。

## 范围排除

- 仅发布 Quant 前端静态资源，服务端 API、D1、研究运行和权限模型保持原边界。
- 导出只覆盖当前批次已成功返回的研究运行；排队、进行中和失败项保留在批次状态中。
- 文件由浏览器本地生成，批量导出不增加网络请求、研究快照或 AI 摘要生成。

## 影响

- `apps/quant-app/src/lib/research-batch-export.ts`：组合现有单报告 Markdown 的批量 formatter 和稳定文件名生成器。
- `apps/quant-app/src/lib/__test__/research-batch-export.test.ts`：覆盖成功报告顺序、部分失败说明、空输入和敏感字段白名单。
- `apps/quant-app/src/App.vue`：在候选对比抽屉增加成功结果批量导出操作和状态反馈。
- `apps/quant-app/src/style.css`：增加批量导出按钮及状态提示的响应式样式。

## 可验证需求

- 批次中至少有一项成功且所有项目已结束时，Quant MUST 提供导出成功报告操作。
- 批量 Markdown MUST 按当前候选顺序包含每项成功报告的现有白名单内容；部分失败时 MUST 标明失败数量和股票代码。
- 成功项为空、批次仍在运行或生成文件失败时，页面 MUST 保持诚实状态并允许后续重试。
