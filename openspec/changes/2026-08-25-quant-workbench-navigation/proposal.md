# Quant 工作台导航与视图分层

## 背景

Quant 当前把总览、观察池、候选表格、投资因子和研究抽屉集中在一个长页面中。数据能力持续增加后，首屏信息密度偏高，用户需要滚动才能进入核心择股流程；同时缺少与其他 Starye 子应用一致的品牌 Header 和稳定导航入口。

## 目标

- 为 Quant 增加与 Movie、Comic 子应用一致的 sticky Header、品牌和响应式导航。
- 将工作台组织为总览、候选研究、观察池、因子框架四个可直达视图。
- 保留现有 API、抽屉、筛选、研究标记和数据刷新行为，降低后续扩展成本。
- 在总览中增加清晰的下一步入口，让金融初学者知道先看什么、再做什么。

## 非目标

- 不新增数据库表、API 路由或数据源。
- 不修改现有信号、价值质量和研究状态公式。
- 不把数据源积分、配额或运行状态放入择股工作台。

## 影响与风险

- 影响 `apps/quant-app` 的页面模板、视图状态和样式。
- 使用 hash 视图状态兼容当前 Gateway/Pages 路径，不引入新的路由部署配置。
- 现有抽屉和加载逻辑继续由 `App.vue` 管理，重组主要改变可见区域，回归重点是视图切换、移动 Header、抽屉和横向表格。

## 验收要求

- Quant MUST 在桌面和移动宽度显示统一 Header，导航项可键盘访问并能切换四个视图。
- 刷新或直接打开带有合法 hash 的 `/quant/` 地址后，页面 MUST 保持对应视图。
- 总览 MUST 只保留统计、优先关注和进入下一步的导航提示；观察池、候选表和因子明细在各自视图展示。
