# 观察池时序外核对

## 背景

单票研究报告已有 optional 时序外证据，但方向判断错误地使用了相对其他状态的留一区间，并把「相对更好」解释成预测上涨。对照状态样本不足时，主导状态完全得不到核对。观察池审计只统计样本内区间是否同向，详情页也不展示时序外结果。

## 目标

- 时序外方向判断只使用该状态更早截点的上涨比例 Wilson 区间是否稳定偏离 50%。
- 观察池按状态展示时序外标的计数，并与样本内结论分开。
- 详情页展示当前状态的时序外样本、一致数和结论。
- 阈值、候选排序、研究动作、AI 和决策就绪度保持不变。

## 非目标

- 不调整 MA、回撤或样本门槛。
- 不把时序外结论写入必选证据、确定性推荐或买卖建议。
- 不合并不同标的的收益率。

## 影响与风险

涉及 API `timing-history` 公式、研究报告 optional 证据版本，以及 Quant 客户端时机计算、观察池审计和详情组件。公式从 `timing-history-walkforward-v1` 改为 `v2`；已保存的旧报告保持原快照。
