# Quant 股本与回购股数证据

## 背景

Quant 已经可以展示实施分红、经营现金流、资本开支、自由现金流和年度分红支付率。股东回报复核还缺少股本变化的可追溯事实：回购可能减少总股本，增发、转股或行权也可能改变每股权益基础。当前结果只把股本变化和回购金额作为缺口，研究报告与详情页缺少可核对的事件记录。

## 目标

- 接入 Eastmoney 股本结构页面的历年股本变动记录。
- 返回最近总股本、相邻事件之间的股数变化、变化比例、变动原因和可识别的回购注销股数。
- 继续把回购金额保留为未接通字段；股数变化不换算为人民币金额。
- 让股本证据与现金流证据并行读取，单只来源失败只影响对应证据区域。
- 在股东回报详情、研究报告和投资知识目录中展示这组可追溯证据，但不改变价值质量分数、因子权重、研究动作或决策推荐。

## 非目标

- 不抓取回购公告全文、成交均价或回购金额。
- 不把股本变化原因中的“回购”解释为完整回购金额，也不将发行、转股、行权等事件混成回购。
- 不新增 D1 表、同步任务或独立 API endpoint；复用受保护的股东回报响应。

## 影响与风险

- API：新增 Eastmoney 股本结构 provider，扩展股东回报 domain、响应 schema、研究证据和 provider/domain/route 测试。
- Quant：扩展 market parser、view model、股东回报详情组件和响应式样式。
- 数据源：复用 `CapitalStockStructure/PageAjax` 的 `lngbbd` 数组，字段为总股本、事件日期和变动原因。
- 风险：同一日期可能存在多个事件，某些股票历史记录可能为空或字段缺失；必须保留原始事件顺序、空值和 provider 错误状态。
