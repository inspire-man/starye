## 设计目标

把当前已有数据源组合成可读的研究证据，而不是引入一个不可解释的总分。证据链在前端以纯函数生成，输入全部来自已认证 API 返回的本地日线、最新估值、财务报告历史、价值质量分和股东回报结果；输出包含公式版本和可展示的证据行，便于单测和浏览器复核。

## 关键决策

1. **名称解析边界**：在 API watchlist POST 和 Quant 前端新增流程中解析名称；当前 provider 为 Tushare 时使用 `stock_basic`，否则使用 Eastmoney 公共行情 origin；用户显式名称优先。网络失败不阻断 CRUD，名称保持 `null`并展示缺口。
2. **候选并集读取**：不修改同步租约和快照持久化。候选 GET 读取当前 watchlist，使用最新快照中仍属于观察池的结果，并为未出现在快照中的代码生成固定的缺数据候选行。同步成功后下一次读取自然替换待更新行。
3. **确认弹窗兼容**：给共享组件增加 `mobilePlacement` 可选 prop，默认 `sheet` 保持现有应用；Quant 传入 `center`，通过 class 控制窄视口对齐。
4. **证据链纯函数**：新增 `decision-evidence.ts`，将五个维度拆为 `pass / caution / missing / fail`，并记录 `source`、`observedAt`、`threshold`、`value`、`detail`。时机结论只由这些状态聚合，不再重复写散落在模板中的文字判断。

## 量化门槛（v1）

- 趋势确认：至少 60 根日线；收盘价相对 MA20 不为负，20 日收益不为负，且 60 日回撤不低于 -15%。
- 估值安全边际：价值质量估值维度可用，或 TTM PE/PB 的池内高位百分位均不超过 67%；缺少比较样本则为 caution。
- 经营质量：最近一期 ROE、净利润同比、经营现金流/营收至少有两项可读且没有明显现金流为负；存在利润增长与现金流为负的背离时为 fail/caution。
- 股东回报：实施分红记录和最新价格可用时展示近 12 个月股息率与分红年数；缺数据只作为缺口，不扣成零分。
- 风险复核：连续上涨达到 5 日、成交量比达到 2 倍、60 日回撤达到 -15% 或价值质量有风险扣分时进入等待/复核。

以上门槛是研究排序和复核窗口，不是收益预测或自动交易规则。

## 失败与降级

- Eastmoney 名称解析失败：保存代码，名称缺口可手填。
- 最新快照不存在：候选 API 返回当前观察池的全量待更新候选集合。
- 任一详情接口失败：该证据行显示数据源失败和观测时间缺失，时机框架降级。
- 移动窄视口：弹窗和证据链使用稳定的 max-width、滚动和换行约束，避免内容遮挡。
