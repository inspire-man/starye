## Why

当前估值速览能显示单只股票的 PE、PB 和 PEG，但金融初学者仍难以判断这些数字在自己的观察池里处于什么位置。行业分类和全市场历史估值接口口径不稳定，本轮先提供一个可核对的观察池内相对比较。

## What Changes

- 新增受保护的观察池估值比较接口，按当前观察池读取并比较 TTM PE、PB。
- 返回比较样本数、可用样本数和目标股票高于多少比例观察池标的的结果。
- 在择股工作台估值区域增加“观察池相对位置”，明确标注比较范围，不给出行业结论或买卖结论。
- 保持按需读取，不新增 D1 表，不改变日线同步和现有估值快照接口。

## Impact

- API：Quant route、估值比较响应 schema、估值 client 类型和解析。
- Frontend：估值速览增加相对位置行和样本状态。
- 测试：增加 API route、client 解析和 UI 构建验证。

## Out Of Scope

- 本轮不接入行业分类、全市场历史分位、盈利预测和同行业样本。
- 本轮不把“估值较低”直接翻译成买入建议，也不改变现有因子评分。
- 本轮不持久化估值比较结果。

## Risks

- 观察池过小或字段缺失会造成排名不稳定：响应显式返回样本数，页面显示样本不足状态。
- PE/PB 对行业和盈利周期敏感：页面使用“高于/低于观察池比例”这一描述，并保留口径提示。

## Requirement Summary

估值比较接口 MUST 只使用当前观察池内经过校验的估值快照计算相对位置；比较样本不足或字段缺失时 MUST 返回 null 位置，不得推测排名。
