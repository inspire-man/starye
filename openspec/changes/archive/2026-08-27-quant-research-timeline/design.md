## 现状

Quant app 在选择股票后通过 `quantApi.getResearchRuns(tsCode)` 读取最近 5 条研究运行，按 API 返回顺序把第一条作为当前报告。当前报告包含确定性 score、status、action、headline 和 evidence；相邻证据变化已经由独立模块负责。

## 方案

新增 `research-run-timeline.ts`，输入 `QuantResearchRun[]` 和可选上限，输出稳定的时间线模型：

- 按 `generatedAt`、`createdAt` 和稳定 id 排序，最新记录在前。
- 每个点保留原始运行 id、时间、状态、动作、分数、headline、证据数和相邻分数 delta。
- 只有前后分数都是有限数字时才计算 delta；缺失分数显示为不可比较。
- 总结最近样本数、最新分数、与上一份报告的 delta、状态变化次数和动作变化次数。
- 通过上限限制渲染项数量，避免历史数据增长导致抽屉失控。

## 展示

轨迹位于当前报告摘要与详细证据之间，采用三项摘要加纵向时间点列表：

1. 最近分数：当前报告的原始 score。
2. 相邻变化：最新报告与上一份报告的分数差；历史不足或数据缺失显示 `--`。
3. 状态 / 动作变化：最近样本中发生过的状态和动作变化数量。

每个时间点显示日期、证据状态、研究动作和分数；分数变化只标记“上升/下降/持平”，并在标题提示这是历史研究轨迹，不是买卖信号。

## 边界

- 0 或 1 条快照：显示历史不足状态，不隐藏当前报告。
- 分数为 `null`、`NaN` 或无穷：保留时间点但不产生 delta。
- 时间字段缺失：使用 `createdAt`，两者都缺失时使用稳定排序兜底。
- 状态或动作变化不会覆盖当前报告的状态、动作和 AI 摘要。
