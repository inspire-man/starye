## Context

Quant 详情抽屉已经使用 `DailyBar` 和 `TrendStructure` 展示 5/20/60 日表现、MA20 偏离和 60 日回撤。新功能只增加前端派生层，保留 API 和 D1 边界；现有 `buildTrendStructure` 作为输入，避免重复改变既有趋势结论。

## Goals / Non-Goals

**Goals:**

- 用一套小而稳定的公式生成时机窗口状态和证据。
- 对中长线研究最有帮助的回撤、均线位置和波动率集中展示。
- 让空数据、窗口不足和边界阈值可由纯函数直接测试。

**Non-Goals:**

- 范围排除买卖点、价格目标、收益预测和自动交易动作。
- 范围排除行业数据、估值 provider 和数据库结构变化。
- 范围排除对候选列表全量重新请求日线；时机窗口只在已选股票详情中计算。

## Decisions

### 1. 复用已有趋势结构

纯函数接收有效日线和 `TrendStructure`，复用既有的 5 日收益、MA20 偏离和 60 日回撤；新计算仅覆盖 MA60 偏离、20 日高点回撤和 20 日收益标准差。

### 2. 状态优先级固定

先判断趋势走弱，再判断短线偏热，再判断回撤观察，最后落到结构平稳。这样严重回撤不会被短线涨幅覆盖，状态结论具有确定性。

### 3. 证据面板使用数据状态而非颜色单独表达

每项指标同时显示名称、数值、阈值和状态；颜色只作为辅助，避免初学者把颜色直接理解成交易信号。提示性口径放入信息图标的 tooltip。

## Risks / Trade-offs

- [阈值属于研究规则] → 页面展示公式版本和阈值，状态只用于筛选与复查。
- [日线样本可能跨越较长自然日区间] → 使用“最近 N 根有效日线”表述，并展示数据截至日期。
- [短期波动率无法预测未来风险] → 标签使用“近 20 日波动率”，不生成目标价或收益承诺。

## Migration Plan

无需迁移。前端部署后，已有详情日线即可即时计算；回滚只移除纯函数和面板，不影响已保存数据。
