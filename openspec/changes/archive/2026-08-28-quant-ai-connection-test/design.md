## 设计

### API 边界

测试路由只接受空 POST，使用当前认证用户和已保存的解密配置。连接 domain 复用 AI 摘要的 endpoint URL 解析和 timeout 上限，发送固定短消息并只验证 HTTP 成功和 OpenAI 兼容响应的最小 `choices[0].message.content` 形状。

### 结果与错误

成功结果只包含 provider、model、测试时间和耗时。缺少配置或 key、超时、非 2xx 和无效响应分别沿用 Quant AI 摘要的配置/超时/上游/无效响应错误码；上游响应正文不会进入错误信息。

### 页面状态

抽屉只测试已保存配置，保存中的表单变化不会改变已保存测试结果。测试期间按钮禁用；成功显示模型和耗时，失败显示可理解的错误并恢复重试，API key 始终保持空白和脱敏。

### 回滚

移除测试路由、连接 domain、client 方法和抽屉测试控件即可；已有配置、研究报告和 AI 摘要生成路径保持不变。
