# Quant 后台定时研究

Quant 已能在页面内自动补齐过期日线、刷新研究标记，并把成功项的复查日推后 7 天。现有闭环仍绑定在浏览器：
unAutomatedResearch 最多 3 只、顺序执行，关闭页面即停止。Worker scheduled 目前只做爬虫日志清理 / lease sweep / GitHub 对账。

本 change 把同一套状态机搬到 API Worker 定时任务：扫描用户观察池中已逾期、今日复查、日线过期或研究报告不足的标的，后台同步日线、生成确定性报告、在已配置 AI 时复核，并持久化任务结果。关闭 Quant 页面后仍继续。

## Goals

- 后台定时处理逾期复查和可刷新的数据缺口，不依赖页面生命周期。
- 复用现有日线同步、研究报告和 AI 摘要，不改推荐/买卖公式。
- 失败按阶段保留，缺失证据不得补零或写成投资结论。
- Overview 只读回看最近一次后台任务。

## Non-goals

- 不修改 MA20/MA60/回撤阈值，不把时机审计写入买卖建议。
- 不把覆盖率、证据分或 AI 未接受结果当成交易信号。
- 不替换页面内 3 项手动自动研究按钮。
- 不把 Quant 任务挂成独立分钟级全量扫描；沿用现有 cron，但按用户冷却和每 tick 批次限流。
