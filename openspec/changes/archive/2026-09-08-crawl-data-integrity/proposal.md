## 背景

Comic 进度沿用旧计数再累加，重复运行或源章节集合收缩时出现已爬数量大于总数。章节 sortOrder 并列时公开与管理列表缺少确定性排序。Movie 新图片来源仍需验证完整样本，历史缺图与匿名播放器隐藏须分开判断。

## 目标

- Comic MUST 依据当前源章节身份和已保存页面重算进度，禁止旧计数累加。
- API MUST 拒绝越界进度，禁止通过钳制把异常变成完成。
- 章节列表 MUST 提供稳定排序，保留重复源记录供完整性检查。
- Movie 媒体失败 MUST 保留既有已保存媒体；完整样本须分别证明来源、持久化、关联和展示。

## 影响与风险

涉及 crawler、API 和管理展示；保持现有身份、R18 权限和播放器可用性门禁。生产历史数据修复基于源快照与读回证据，不按标题合并、不从检测覆盖率推断缺页。
