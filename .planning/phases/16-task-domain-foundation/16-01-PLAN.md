## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-16-01 | Tampering | `crawler_run` state writes | high | mitigate | `repository.ts` predicates each transition on status, `state_version`, and `last_event_sequence`, then writes the transition audit in the same D1 batch. |
| T-16-02 | Denial of Service | template launch contention | high | mitigate | `crawler_template_lease.template_key` is the atomic owner key; conflict returns the extant active run instead of creating parallel work. |
| T-16-03 | Repudiation | retry/cancel/lost-run history | medium | mitigate | append transition rows, immutable task snapshot/attempt numbering, and safe audit records preserve the decision source and reason. |
| T-16-04 | Information Disclosure | detailed run logs | high | mitigate | repository accepts only safe structured input, enforces row/byte caps, and deletes only expired `crawler_run_log` rows while retaining terminal summaries. |
| T-16-SC | Tampering | package supply chain | low | accept | This plan installs no package; lockfile and package manifests are outside its file list. |
</threat_model>
