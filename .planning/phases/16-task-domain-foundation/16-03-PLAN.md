## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Runner/Actions request → internal event route | Untrusted network request claims authority to mutate an application run. |
| Event normalization → D1/audit/error output | Runner-controlled text/metadata could become durable or visible operational data. |
| Worker scheduler → D1 log cleanup | Automatic maintenance may delete data if scope is too broad. |
