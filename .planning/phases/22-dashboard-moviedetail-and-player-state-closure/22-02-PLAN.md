| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-22-05 | Tampering | MovieDetail source cards | high | mitigate | Apply Wave 1 eligibility/type policy before rendering playback or transfer actions; keep inactive/ineligible rows informational. |
| T-22-06 | Tampering | direct/magnet router actions | high | mitigate | Route direct through the existing Player query contract and route magnet through existing TorrServer/Aria2 composables; avoid raw direct URL playback links. |
| T-22-07 | Information disclosure | readiness and source health DOM | medium | mitigate | Render only bounded disposition, reason, revision, observation and source type fields; preserve existing sentinel tests for URL, request and signature material. |
| T-22-08 | Denial of service | repairing actions | low | mitigate | Disable playback while repair is active and expose explicit refresh/readback action, preserving one server-owned state transition path. |
| T-22-SC | Tampering | package installs | low | accept | This plan adds no package installation; existing workspace dependencies remain the supply-chain boundary. |
</threat_model>
