<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| Actions runner → internal API | signed callback crosses the public control-plane boundary |
| workflow inputs → target-profile | provider-supplied values cross into prepared mutation |
| event envelope → D1 | replayable event data crosses into durable lifecycle state |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-18-07 | Spoofing | callback route | critical | mitigate | independent HMAC, key rotation, freshness, nonce/event/sequence and exact run binding |
| T-18-08 | Tampering | workflow inputs | high | mitigate | strict four-field dispatch envelope, schedule bucket, server-owned target registry |
| T-18-09 | Replay | event persistence | high | mitigate | idempotent event insert with body-hash conflict and sequence CAS |
</threat_model>
