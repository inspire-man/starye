| Boundary | Description |
|---|---|
| Worker → GitHub REST | request-scoped bearer token crosses an external provider boundary |
| binding/private key → Web Crypto | secret material enters signing code |
| caller input → Actions client | untrusted template/run data crosses a closed provider registry |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-18-05 | Information Disclosure | token exchange/client | critical | mitigate | in-memory token scope, redacted errors, no raw response/header logging |
| T-18-06 | Elevation | Actions client inputs | high | mitigate | snapshot-derived URL/repository/ref/Environment and four-field payload allowlist |
