<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| admin/API → provider snapshot | caller-controlled template crosses into server-owned registry |
| Worker binding → App client | private key and installation identity enter request-scoped crypto code |
| API → D1 | provider facts cross into durable audit storage |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-18-01 | Elevation | provider snapshot mapper | high | mitigate | closed template registry, fixed target/workflow fields, strict lengths |
| T-18-02 | Information Disclosure | App binding/schema | high | mitigate | secret names only in Env types; redacted facts schema; token-shaped field tests |
| T-18-03 | Tampering | provider association uniqueness | high | mitigate | typed provider lookup indexes and immutable application-attempt binding |
</threat_model>
