<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Provider observation to D1 repository | External workflow status and runner facts request state changes. |
| Older attempt to current task/source projection | Late callbacks can race the current attempt and source revision. |
| Receipt candidate to source readback | Runner-provided receipt data must be checked against persisted state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-23-10 | Tampering | Run/task retry state | high | mitigate | D-06 through D-09 bound retry causes, count, timing, new records, and task-level projection in one repository lifecycle. |
| T-23-11 | Replay | Runner/provider facts | high | mitigate | D-10 and D-13 append signed facts and use event identity, nonce, sequence, and state-version CAS for duplicate/stale/conflict classification. |
| T-23-12 | Tampering | Current source revision | critical | mitigate | D-10 and D-11 require expected source revision and current application-attempt CAS before current projection mutation. |
| T-23-13 | Spoofing | Repair receipt | high | mitigate | D-12 compares movie identity, revision, observedAt, bounded source summary, and authoritative readback before repair success. |
| T-23-14 | Denial of Service | Reconciliation window | medium | mitigate | D-08 bounds polling and waits only for the configured reconciliation window before loss/lease recovery. |
</threat_model>
