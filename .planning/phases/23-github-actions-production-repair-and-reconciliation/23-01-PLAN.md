## Trust Boundaries

| Boundary | Description |
|---|---|
| Admin/API to provider client | Server-owned task and provider data crosses into the GitHub Actions REST boundary. |
| Provider client to GitHub Actions | The provider receives only the fixed dispatch binding and server-held authorization. |
| Provider result to API projection | Provider status and metadata are untrusted observations before validation and redaction. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-23-02 | Spoofing | GitHub App provider request | high | mitigate | Reuse the existing installation-token boundary and reject snapshot/provider binding mismatches per D-17. |
| T-23-03 | Information Disclosure | Provider summary DTO | medium | mitigate | D-15 and D-17 allowlist provider fields and reconstruct the numeric run link; credentials and raw provider material stay server-side. |
