<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Dashboard browser -> Gateway admin route | Authenticated user interaction and query parameters are untrusted. |
| API DTO -> Vue template | Server-projected fields must stay allowlisted at the display boundary. |
| Dashboard -> Movie Viewer | Same-movie identity crosses navigation and must not become a caller-supplied URL. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-10 | Spoofing | repair confirmation | high | mitigate | Send only server-validated movie identity/reason/intent through the authenticated Gateway session. |
| T-24-11 | Tampering | current-attempt projection | high | mitigate | Promote only server `latestRunId`/current attempt and preserve older history as immutable rows. |
| T-24-12 | Information Disclosure | Crawlers.vue | high | mitigate | Render the API allowlist only; tests reject raw URL, token, cookie, signature, and runner fields. |
| T-24-13 | Repudiation | status/history UI | medium | mitigate | Show bounded timestamps, tuple identity, and stable duplicate/conflict/late/stale/ignored outcomes. |
| T-24-14 | Denial of Service | polling lifecycle | medium | mitigate | Poll only while visible, every five seconds, stop on hidden/unmount, and retain last valid data. |
</threat_model>
