<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser media/provider -> Player | Media events and source responses are untrusted observations. |
| MovieDetail/Player -> evidence harness | Only visible, bounded, allowlisted UI facts are observed. |
| Player route -> API | Ordinary playback is not a privileged evidence write. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-15 | Tampering | Player success state | high | mitigate | Require visible click, canplay, playing, two samples, one-second delta, and no terminal error. |
| T-24-16 | Information Disclosure | source cards/player state | high | mitigate | Render source type/health and bounded reason only; exclude raw media URL and signed material. |
| T-24-17 | Denial of Service | source retry/fallback | medium | mitigate | Track visited attempts, cap current source at two retries, and terminate after candidates are exhausted. |
| T-24-18 | Spoofing | same-movie Viewer handoff | medium | mitigate | Use server-owned content code/source revision and existing route, never caller-supplied navigation URLs. |
| T-24-19 | Repudiation | media event timeline | medium | mitigate | Record observed and not-observed allowlisted event rows with bounded timestamps and source attempts. |
</threat_model>
