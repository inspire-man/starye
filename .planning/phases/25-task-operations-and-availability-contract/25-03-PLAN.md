| Boundary | Description |
|---|---|
| signed runner -> internal Hono route | Untrusted callback payload crosses signature, freshness, path and closed-schema checks. |
| route/adapter -> D1 | Bounded observation facts cross into append-only history and current projection. |
| older attempt/revision -> current projection | Late or stale data attempts to overwrite a newer server-owned fact. |
| D1 -> cache/readback consumer | Durable authoritative result is projected to cache invalidation and later API consumers. |
