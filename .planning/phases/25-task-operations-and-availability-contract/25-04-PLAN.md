<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| authenticated browser -> Gateway/API | Browser actions and task detail query parameters are untrusted input crossing the canonical Gateway. |
| API DTO -> Dashboard state/DOM | Server-owned bounded lifecycle, availability, observation and audit facts become visible UI state. |
| Dashboard/Gateway proof -> fixture/readback | Test script consumes fresh tuple identities and could accidentally persist secrets, raw URLs or unbounded evidence into artifacts. |
| cache/current projection -> UI | A stale response could present obsolete availability unless authoritative refresh and history ordering are asserted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-25-04-01 | Tampering | typed lifecycle wrappers and UI actions | high | mitigate | Closed request types, allowlisted fields, server route status handling and exact action tests; client never constructs workflow/URL/command/secrets. |
| T-25-04-02 | Information disclosure | `Crawlers.vue` and proof artifacts | high | mitigate | Render only bounded DTO fields and redacted labels/codes/counts; sentinel tests reject URL, token, cookie, signed material, raw response, media and unbounded payload. |
| T-25-04-03 | Tampering/Inconsistent state | current availability readback and polling | high | mitigate | Reload detail after mutation, preserve history separately, assert cache invalidation before newest current is shown, and prove stale/late outcomes do not replace current. |
| T-25-04-04 | Repudiation | task history/audit projection | medium | mitigate | Display task-scoped actor, reason, timestamp and bounded outcome summary from authoritative audit DTO with stable ordering and cursor limits. |
| T-25-04-05 | Denial of service | list/detail/history polling | medium | mitigate | Fixed page/log/history limits, visible-only polling, no raw payload rendering, and fixture-only bounded network interactions. |
| T-25-04-SC | Tampering | package installs | low | accept | No dependency installation or lockfile change is planned; use the existing workspace toolchain. |
</threat_model>
