## Trust Boundaries

| Boundary | Description |
|---|---|
| client -> server contract | untrusted operation/target/policy/intent and idempotency input enters the API domain |
| runner/provider -> server persistence | signed or provider-derived result attempts to append observation and update projection |
| server -> D1 | JSON snapshot, bounded observation and evidence cross into durable storage |

</threat_model>
