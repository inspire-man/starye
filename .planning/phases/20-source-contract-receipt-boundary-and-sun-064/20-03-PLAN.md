<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API readiness DTO -> Dashboard | authenticated admin detail consumes server-owned task/run/source facts |
| API MovieDetail -> public movie client | public/R18-gated response crosses into browser rendering and playback selection |
| browser route -> xgplayer/view tracking | untrusted route/query state must be checked before player construction or analytics |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-20-08 | Tampering | `MovieDetail.vue` and `Player.vue` readiness gate | high | mitigate | require server-owned disposition plus eligible source before constructor/view tracking; never trust route query or array position alone |
| T-20-09 | Information Disclosure | Dashboard/MovieDetail DTO rendering | high | mitigate | typed allowlist projection, bounded reasons, existing session/R18 guards, and tests asserting no raw receipt/credential-shaped field is rendered |
| T-20-10 | Spoofing | admin task detail identity tuple | medium | mitigate | bind display to validated primaryContentId/movie.id and preserve existing task template/resource ownership checks |
| T-20-11 | Denial of Service | source failure/loading states | low | accept | UI renders bounded error/loading states and controlled retry/readback; provider execution and repair orchestration remain under existing server-owned boundaries |
</threat_model>
