<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| Dashboard request -> API route | template, cursor and task IDs are caller-controlled |
| API route -> D1 read model | durable task/provider/receipt facts cross into a response projection |
| API -> provider association | provider metadata may contain URL-like or credential-adjacent fields |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-19-01 | Elevation | crawler task routes | high | mitigate | repeat session/resource/task/run checks on every route |
| T-19-02 | Information Disclosure | provider/receipt projection | high | mitigate | allowlisted fields, server-owned URL derivation, redaction tests |
| T-19-03 | Tampering | keyset cursor and lifecycle actions | high | mitigate | opaque signed/encoded tuple, bounded validation, repository CAS |
</threat_model>
