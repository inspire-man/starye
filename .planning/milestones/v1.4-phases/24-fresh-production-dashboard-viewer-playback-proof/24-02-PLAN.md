<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Gateway authenticated browser -> admin route | Session and task ownership are untrusted request boundaries. |
| API route/repository -> D1 | Tuple facts and artifact references cross into durable storage. |
| D1/API -> Dashboard DTO | Stored facts must remain bounded and redacted before rendering. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-05 | Spoofing | evidence POST session | high | mitigate | Reuse admin auth and task/run ownership checks on the Gateway session. |
| T-24-06 | Tampering | evidence repository | high | mitigate | Tuple/content/source-revision validation, hash conflict detection, and CAS transaction ordering. |
| T-24-07 | Repudiation | rejection history | medium | mitigate | Append bounded duplicate/conflict/stale/late/ignored outcomes with stable codes. |
| T-24-08 | Information Disclosure | task detail DTO | high | mitigate | Server-owned allowlist and route tests excluding raw URLs, signatures, tokens, cookies, and runner payloads. |
| T-24-09 | Denial of Service | POST/replay path | medium | mitigate | One bounded terminal summary per tuple, finite schema limits, and indexed idempotency lookup. |
</threat_model>
