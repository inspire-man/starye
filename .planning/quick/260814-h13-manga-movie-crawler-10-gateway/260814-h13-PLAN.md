# Manga/Movie crawler 10-item batch

## Goal

将实际生效的 Manga/Movie crawler 每次运行处理上限收敛到约 10 条，保留并发、重试、延迟和凭据边界不变，并用单元测试、类型检查、lint 与 canonical Gateway 状态检查验证。

## Tasks

1. 更新 `packages/crawler/src/config/crawl.config.ts` 的 Manga 默认批次限制，将漫画、新章节、更新章节都设为 10；更新 `packages/crawler/src/types/config.ts` 的 Movie/GitHub Actions 限制，将影片和页数设为 10。
2. 同步 `packages/crawler/.env.example` 的示例批量参数，并补充针对生产配置常量与 Manga 默认配置的回归断言，避免后续回到大批次或无限制。
3. 运行 crawler 定向测试、`pnpm lint`、`pnpm type-check`，启动/检查本地 Gateway `http://localhost:8080`，记录服务与健康状态及任何外部依赖限制。

## Verification

- `pnpm --filter @starye/crawler test -- --run ...` 相关测试通过。
- `pnpm lint` 与 `pnpm type-check` 通过。
- 配置输出明确显示 Movie `maxMovies=10`、Manga `maxMangasPerRun=10`、新/更新章节均为 10。
- Gateway 通过 `http://localhost:8080` 返回可用响应；若 crawler 需要远程凭据或 provider tuple，则只验证本地配置/入口状态，不伪造成功。
