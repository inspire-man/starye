# 目标

让 R18 影片在 SFW 账号下明确表达访问边界，只保留有效的访问状态入口，隐藏不适用的播放、来源检查或技术来源信息。

# 必须满足

- 影片详情首屏和观看状态区都明确显示播放源受访问权限保护。
- SFW 账号不显示立即播放、选择播放方式、重新检查或视频来源检查动作。
- 即使服务端意外返回播放器数据，受限态也不渲染播放源卡片。
- 访问状态入口统一指向详情页内部的个人中心路径，并保留 DOM 合约覆盖。
- 普通账号既有播放、来源检查和技术详情行为保持不变。
