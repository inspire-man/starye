<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| browser -> Gateway `/torrserver/*` | Untrusted paths, queries, methods, headers, and cookies reach a public Worker route. |
| Gateway -> TorrServer | Only the server-configured origin may receive rewritten requests; the response body may be multi-gigabyte and must remain streamed. |
| Movie route/query -> Player | A stream URL is untrusted until its origin, exact path, scheme, credentials, and required parameters match a trusted base. |
| Player events -> playback evidence | Media events and tuple identity must agree before bounded evidence is persisted or promoted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-26-Q1 | Server-Side Request Forgery / Tampering | Gateway target resolution | high | mitigate | Use only local fixed origin or validated `TORRSERVER_ORIGIN`; reject caller target inputs and prefix-confusion paths. |
| T-26-Q2 | Information Disclosure | upstream request headers | high | mitigate | Strip cookie, authorization, host, and unrelated credentials before proxying; expose only bounded response headers. |
| T-26-Q3 | Denial of Service | media body/cache path | high | mitigate | Preserve the upstream stream, bypass KV/body serialization, force no-store, and avoid buffering response bytes. |
| T-26-Q4 | Spoofing | Player stream URL | high | mitigate | Require a trusted origin/base, exact controlled stream path, HTTP(S), no URL credentials, and link/index parameters. |
| T-26-Q5 | Repudiation | playback readiness | high | mitigate | Bind explicit play/canplay/playing/time delta to the server-owned tuple and verify Admin/Public/Dashboard authoritative readback. |
| T-26-Q6 | Information Disclosure | playback evidence | high | mitigate | Persist bounded event/revision/tuple facts only; exclude magnet/stream URLs, headers, cookies, credentials, and media. |
| T-26-SC | Tampering | package supply chain | low | accept | No package installation or dependency change is planned. |
</threat_model>
