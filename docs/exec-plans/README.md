# Execution Plans

执行计划是可审阅、可验证、可追踪的工作工件。

| 类型 | Canonical owner |
|------|-----------------|
| 当前 milestone / phase | ../../.planning/ |
| 跨 API、数据库、前端或多步骤能力 | ../../openspec/changes/ |
| 已完成能力和历史 change | ../../openspec/changes/archive/、../../.planning/milestones/ |
| 轻量局部计划 | 本目录 |

active/ 和 completed/ 只用于轻量计划，不复制 OpenSpec 或 phase 文件。
